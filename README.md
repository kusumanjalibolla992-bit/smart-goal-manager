# smart-goal-manager
Smart Goal Manager is a simple web app that helps users set, track, and manage their personal and professional goals in an organized way. It is built using HTML, CSS, and JavaScript with local storage support for saving progress in the browser.
## ✨ Features

- Add new personal or professional goals  
- Track progress of each goal  
- Mark goals as completed  
- Clean and simple user interface  
- Data stored using browser local storage (no backend required)

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)
